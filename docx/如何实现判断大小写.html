如何实现判断大小写

距离法

这是最简单的一个方法，你只需要创建一个名为“ABCDEFGHIJKLMNOPQRSTUVWXYZÄÖÜÀÂÆÇÉÈÊËÏÎÔŒÙÛŸАБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯΑΒΓΔΕΖΗΘΙΚΛΜΝΞΟΠΡΣΤΥΦΧΨΩ”的角色（这其中包含了英语、俄语、德语、法语、西班牙语、希腊语的大写字母），并在该角色中添加下面的代码： 

定义 (字母) 是大写？
将[i v]设为(1)
将[字符串 v]设为()
重复执行([ABCDEFGHIJKLMNOPQRSTUVWXYZÄÖÜÀÂÆÇÉÈÊËÏÎÔŒÙÛŸАБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯΑΒΓΔΕΖΗΘΙΚΛΜΝΞΟΠΡΣΤΥΦΧΨΩ]的字符数)次
    如果 < ([ABCDEFGHIJKLMNOPQRSTUVWXYZÄÖÜÀÂÆÇÉÈÊËÏÎÔŒÙÛŸАБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯΑΒΓΔΕΖΗΘΙΚΛΜΝΞΟΠΡΣΤΥΦΧΨΩ]的第(i)个字符)=(字母) > 那么
        将[字符串 v]设为(连接(字符串)和(字母))
    否则
        将[字符串 v]设为(连接(字符串)和([ABCDEFGHIJKLMNOPQRSTUVWXYZÄÖÜÀÂÆÇÉÈÊËÏÎÔŒÙÛŸАБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯΑΒΓΔΕΖΗΘΙΚΛΜΝΞΟΠΡΣΤΥΦΧΨΩ]的第(i)个字符))

    将[i v]增加(1)

将[是大写字母？ v]设为<(到(字符串)的距离)=(0)>

当然，如果你只想判断英文字母或者更多字符，可以将角色的名称更改为相应的大写字符集，同时把这串脚本中的也改一下。

53个造型法

这是相对复杂的一个方法，因为它利用的是造型名称区分大小写，需要你创建很多的造型。例如，一个角色可以有一个名为“A”的造型和一个名称为“a”的造型。

换成( v)造型可用于切换到给定名称的造型，(造型 [编号 v])可用来通过造型编号区分它们。

这种方法需要为每个要检测的字母创建成对的造型——一个大写字母和一个小写字母。当找不到字母时，还需要一个名为“null”的附加造型作为默认造型。对于这个例子，造型的顺序应该是：null、A、a、B、b、C、c…… 


定义 (字母) 是大写？
换成(null v)造型
换成 (字母)造型 // 尝试切换到给定角色的造型
如果 <(造型 [名称 v]) = [null]> 那么
  将 [是大写字母？ v] 设为 [] // 如果找不到字母，则返回空值
否则
    将 [是大写字母？ v] 设为 <((造型 [编号 v]) 除以(2)的余数) = [0]> // 造型编号 2, 4, 6, ... 是大写字母；造型编号 3, 5, 7, ... 是小写字母
结束

当然，如果你只想判断英文字母或者更多字符，可以将角色的名称更改为相应的大写字符集，同时把这串脚本中的也改一下。
