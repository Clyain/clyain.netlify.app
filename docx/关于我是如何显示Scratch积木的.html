关于我是如何显示Scratch积木的

在这个部分，我将介绍我如何在网页中显示Scratch积木的。

有些人可能会使用TurboWarp之类的编辑器，或者在官网通过 ScratchAddons 提供的插件将积木转换为SVG或PNG格式的图片，并直接在HTML中引入文件以显示，可是它不易于修改。

而我使用的是一个名为 Scratchblocks 的JavaScript库来渲染积木。这个库允许我直接在HTML中编写积木的文本表示，并将其转换为可视化的积木图像。这种方法使得修改和更新积木变得非常方便，因为我只需要更改HTML内的文本内容，而不需要重新生成图片。

这里也有一个可视化的网站链接：scratchblocks.github.io，可以结合着下方的Scratchblocks语法来使用并尝试搞懂它。

调用Scratchblocks

点击下载所需要的文件：scratchblocks-v3.6.4-min.js 和 translations-all-v3.6.4.js
下载之后需要在HTML的<head>标签中添加以下代码： 

<script src="scratchblocks-v3.6.4-min.js"></script>
<script src="translations-all-v3.6.4.js"></script>


并在<body>标签的末尾添加以下代码： 

<script>
    scratchblocks.renderMatching("pre.normal", {
        style: "scratch3",
        languages: ["zh_cn", "en"],
        scale: 0.675
    });
    scratchblocks.renderMatching("code.inline", {
        inline: true,
        style: "scratch3",
        languages: ["zh_cn", "en"],
        scale: 0.675
    });
</script>
之后你就可以在HTML中使用Scratchblocks了。

在上述的这个代码中，

  • 参数style接受的值有（三选一）："scratch2"、"scratch3"、"scratch3-high-contrast"（即高对比度样式），默认为"scratch2"。
  • 参数languages接受一个语言代码数组，支持的语言包括："en"（英文）、"zh_cn"（简体中文）等。
  • 参数scale用于设置积木的缩放比例，默认为1。


如果你需要渲染一整块积木栈，可以使用以下代码（省略号应被填入你的代码）： 

<pre class="normal">
...
</pre>


而如果你需要在行内渲染积木，则可以使用以下代码（省略号应被填入你的代码）： 

<code class="inline">
...
</code>

:: [category or #color] [shape]
 强制积木以特定方式显示。可能的类别包括：motion, looks, sound, pen, variables, list, events, control, sensing, operators, custom, custom-arg, extension, grey, obsolete。

另一种设置颜色的方法是通过扩展形状设置，但这不与其他颜色兼容。

可能的扩展颜色包括：music, pen, video, tts OR text2speech, translate, wedo OR wedo2, ev3, microbit, makeymakey, gdxfor, boost。

#color 可以是任何十六进制 RGB 颜色，例如 #ff0000 会产生纯红色。

可能的形状包括：hat, stack, ring, boolean, reporter, cap, cat。
